# Vikash Pandey Portfolio (frontend only)

Plain HTML, CSS and JavaScript. No build step, no backend, no keys.

- `index.html`  page content
- `style.css`   all styling (colors are tokens at the top of the file)
- `script.js`   hero animation and copy buttons
- `assets/me.jpg` your photo (replace the file to change it)

Open `index.html` in a browser, or host the folder on Netlify, Vercel or GitHub Pages.
Fonts load from Google Fonts, so the page needs an internet connection to show them.
